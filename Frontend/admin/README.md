# RestaurantFlow Admin

Primera etapa visual del panel de administración. La única vista implementada es **Vista en vivo** y todos sus datos son mocks locales.

## Ejecutar

```bash
npm install
npm run dev
```

Abre la URL indicada por Vite. El build usa la base `/admin/` para despliegue.

## Límites actuales

- Sin backend, fetch, WebSockets, Portal ni IA real.
- El mapa RPG se construye con CSS y está preparado para sustituirse por assets pixel-art definitivos.
- Los demás items del sidebar son placeholders visuales.
